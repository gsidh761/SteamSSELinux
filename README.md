# SteamSSE Linux
v1.0.0 (Based on Steam SSE 4.2.0)

<br>

> [!WARNING] 
> This project currently only supports distros with the DNF Package Manager! 
> 
> As a workaround, run `installer.sh` and afterwards manually install **xorg-x11-server-Xwayland** using your distro's package manager

<br>

**Installation**

Run the following command to install SteamSSELinux:

`./installer.sh`

**Launching the Emulator**

After the installation, launch the emulator using the SteamSSE Emulator shortcut from the Start Menu or using the `launch_steem` command.
